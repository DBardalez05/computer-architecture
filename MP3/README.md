# MP3: RGB Game of Life

Three independent Games of Life run on an 8×8 LED matrix using the iceBlinkPico. Each game controls a red, green, or blue channel. When living cells overlap, their colors combine.

- [Demo video](https://youtu.be/aNmRook06YM)
- [Project report](https://docs.google.com/document/d/1NeukE8pDAEfVfh82RwiXy0xJk_hNCUKkz_sfYWxR5EU/edit?usp=sharing)

This folder contains the SystemVerilog source files, testbenches, starting grids, and simulation screenshots.
